# Play Sigorta - Acente Yönetim Platformu Landing Page

Modern, responsive landing page tasarımı. İhsan Bey için hazırlandı.

## Özellikler

- ✨ Modern ve şık tasarım
- 📱 Tam responsive (mobil, tablet, desktop)
- 🎨 Framer Motion animasyonlar
- ⚡ Next.js 16 + TypeScript
- 🎯 SEO optimize
- 🚀 Hızlı performans

## Kurulum

```bash
npm install
```

## Geliştirme

```bash
npm run dev
```

Tarayıcıda aç: [http://localhost:3000](http://localhost:3000)

## Canlıya Alma

### Vercel ile (Önerilen - Ücretsiz)

1. [Vercel](https://vercel.com)'e git
2. GitHub ile giriş yap
3. "Import Project" > Bu repo'yu seç
4. "Deploy" bas - 2 dakikada canlıda!
